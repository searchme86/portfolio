chartJs를 이용한 커스텀 그래프 구현

회사 상품 대시보드용 차트 프로토타입으로, Chart.js 기본 기능을 실무 요구사항에 맞게 커스터마이징한 데이터 시각화 솔루션

  • 프로젝트 개요:

    회사 상품 대시보드에 사용될 차트 프로토타입으로 개발했습니다. Chart.js 기본 기능으로는 충족되지 않는 디자인 및 기능 요구사항을 커스터마이징을 통해 해결했습니다.

  • 개발 동기:

    기존 Chart.js의 기본 툴팁과 차트 스타일의 한계를 극복하고, 실무에서 요구되는 구체적인 디자인과 기능을 구현하기 위해 Canvas API 직접 조작과 Chart.js 플러그인 시스템을 활용했습니다.

  • 핵심 목표:
    • lineWithBar 그래프 - Mixed Chart Type으로 라인과 바 차트 조합
    • lineVertical 그래프 - 그래프 포인트 간 세로선 표시
    • 커스텀 툴팁 - 디자인 요구사항에 맞는 스타일로 변경
    • Gap 계산 시스템 - 그래프 포인트 간 값 차이를 툴팁에 표시
  • 주요 성과:

    이 프로젝트를 통해 Canvas API 직접 조작과 커스텀 애니메이션 구현에 대한 깊이 있는 이해를 얻을 수 있었으며, 특히 그래프 간 값 차이 계산 로직과 세로선 렌더링을 위한 기술적 역량을 확보했습니다.

기술스택

이 프로젝트에서 사용된 주요 기술들과 그 선택 이유를 소개합니다.

  • 메모리 관리

기술 선택 이유:

Chart.js를 선택한 가장 큰 이유는 유연한 커스터마이징과 안정적인 성능입니다. 특히 Canvas API를 직접 조작할 수 있는 플러그인 시스템은 복잡한 커스텀 기능을 구현할 수 있게 해주며, 다양한 차트 타입을 조합한 Mixed Chart 구현이 가능합니다.

상세정보

  • 실제 동작 영상:

    📹 lineVertical 그래프 동작 영상
    📹 lineWithBar 그래프 동작 영상

  • 핵심 기술적 도전과 해결:

    Chart.js 기본 툴팁과 차트 스타일 한계를 극복하기 위해 Canvas API 직접 조작과 Chart.js 플러그인 시스템을 활용했습니다. 특히 그래프 간 값 차이 계산 로직과 세로선 렌더링을 위한 커스텀 애니메이션을 구현했습니다.

  • lineWithBar 그래프 구현:

    Mixed Chart Type을 활용하여 라인 차트와 바 차트를 하나의 캔버스에 조합했습니다. 각 데이터셋의 독립적인 스타일링과 인터랙션을 보장하면서도 통일된 사용자 경험을 제공합니다.

  • lineVertical 그래프 시스템:

    그래프 포인트 간 세로선을 표시하는 커스텀 기능으로, Canvas API를 직접 사용하여 각 데이터 포인트에서 X축까지 수직선을 그립니다. 이를 통해 데이터의 시각적 가독성을 크게 향상시켰습니다.

  • Gap 계산 및 표시 시스템:

    연속된 데이터 포인트 간의 값 차이를 실시간으로 계산하고 툴팁에 표시하는 기능입니다. 사용자가 데이터 변화량을 직관적으로 파악할 수 있도록 도와줍니다.

  • 커스텀 툴팁 디자인:

    Chart.js 기본 툴팁의 한계를 벗어나 완전히 새로운 디자인의 툴팁을 구현했습니다. HTML과 CSS를 활용한 리치한 콘텐츠 표시가 가능하며, 반응형 포지셔닝과 애니메이션 효과를 포함합니다.

  • 성과와 학습:

    이 프로젝트를 통해 단순한 라이브러리 사용법을 넘어서서, Canvas API의 저수준 조작과 데이터 시각화 최적화 기법에 대해 깊이 있게 이해할 수 있었습니다. 특히 실무 환경에서 요구되는 커스터마이징 역량과 성능 튜닝 경험을 쌓을 수 있었습니다.
